# n8n on Render (Free)

This repo deploys **n8n** to Render using a Blueprint (`render.yaml`).

## Deploy
1. Push this repo to GitHub
2. In Render: New -> Blueprint -> select this repo
3. Deploy

## Important
- Free instances can spin down on inactivity.
- Timezone is set to Asia/Tashkent via `GENERIC_TIMEZONE`.
